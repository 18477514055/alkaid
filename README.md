# 瑶光 Alkaid

**极简内核 + 插件化的个人 AI Agent 平台。**

A minimal-core, plugin-based personal AI agent platform that runs entirely on your own machine.

```
后端 Fastify + node:sqlite   ／   前端 React 19   ／   桌面端 Electron
内核 ~20k 行 TypeScript      ／   前端 ~15k 行    ／   单机运行，数据不出本机
```

---

## 这是什么

瑶光不是「又一个聊天框」。它想做的是一个**能长期用下去的本地 Agent 工作台**：

- **数据在你机器上** —— 对话、记忆、工具调用记录都在本地 SQLite 里，不经过任何中间服务器；
- **模型只是引擎** —— 换模型、换网关、换供应商，不用重建上下文与工作区；
- **能真的动文件** —— 授权工作区、跑命令、读写代码，权限档位说清楚能做什么；
- **记得住事** —— 项目级长期记忆，但**模型只能提议，不能自己拍板**。

## 功能

### 对话与模型
- 任何 **OpenAI 兼容端点**都能接（官方 API、自建网关、本地推理服务）
- 每个连接可设**模型白名单**；选择器支持**搜索**与**按提供商分类**
- 上下文窗口档位（32k / 64k / 128k / 200k / 500k / 1M）与**思考强度**逐会话可调
- 模型输出中，发送键会变成**停止键**；输入框里有内容时保持发送 —— 这一下是**插话**（排进当前这一轮的下一个步骤，不新开一轮）

### 工作区与项目
- 工作区 = 你**显式授权**给 Agent 的目录；桌面端可以直接拉起系统目录选择器
- 项目有自己的共享目录与**独立记忆**，删对话不会碰到项目文件
- 每个对话有「当前目标 / 有序任务 / 动态」的执行看板，右侧栏与委托看板都按 Markdown 渲染

### 工具系统
- **内置工具**（文件、命令、检索等）、**MCP 服务器**、**插件工具**三类统一管理
- 每个工具三态：**常驻 / 按需 / 关闭**；支持**按分类整组批量**设置与折叠
- 权限档位：`readonly` / `workspace` / `project` / `workspace_project` / `full` —— **可见性也是权限**：看不到的工具不会出现在模型的工具表里

### 项目记忆（这是本项目的重点）
- 模型**只能提交提案**；正式记录由人工或维护 AI **独立审批**后才写入
- **原则类记录永不由 AI 批准、修改或删除**
- 可选「对话结束后自动批准不冲突的提案」—— 冲突的、多条的、以及原则，一律留在暂存区等人
- 暂存区的文本，**来源对话自己可以改**（不必走审批），但改不了性质与目标版本
- 记忆 100% 本地、按项目隔离，不写进工作区文件、不上云

### 子代理与团队
- 主对话可以派**子代理**（它是一个**真实会话**，可以点进去看它的完整过程）
- Agent Team 共享任务板协调并行工作；写作用域重叠只是**建议**，不是锁
- 子代理**可以只读所有东西，但只能改自己的看板**

### 上下文压缩
- 上下文接近窗口上限时自动压缩，也可手动触发
- 摘要**带原文指针**，被压掉的原文永远可以逐字回读
- 压缩不会删除任何消息

## 环境要求

| 项 | 要求 |
|---|---|
| Node.js | **≥ 24**（用到 `node:sqlite` 与原生 TypeScript 执行，无需编译步骤） |
| 包管理器 | pnpm（推荐）或 npm |
| 系统 | Windows 10/11（主要开发与测试平台）；macOS / Linux 理论可用但未系统验证 |

## 快速开始

```bash
git clone https://github.com/18477514055/alkaid.git
cd alkaid
pnpm install

# 构建前端产物
pnpm web:build

# 启动（后端 + 网页界面）
pnpm start
```

打开终端里打印的地址（默认 `http://127.0.0.1:8787`），然后在 **设置 → 连接** 里添加你的模型端点：

- **Base URL**：如 `https://api.deepseek.com/v1`
- **API Key**：只保存在本机的密钥文件里
- **模型**：填模型 id，或点「拉取模型」

### 桌面端

```bash
pnpm desktop            # 直接以 Electron 运行
node scripts/build-dist.mjs   # 打包出 release/YaoGuang-win32-x64
```

### 数据位置

| 环境 | 路径 |
|---|---|
| 命令行启动 | `~/.alkaid`（可用 `ALKAID_HOME` 覆盖） |
| 桌面端 | `%APPDATA%\alkaid` |
| 端口 | 默认 `8787`（可用 `ALKAID_PORT` 覆盖） |

数据库是单个 SQLite 文件，**备份就是复制这个文件**。

## 开发

```bash
pnpm typecheck     # 双 tsconfig：后端 + 前端
pnpm test          # node --test，全量
pnpm gate          # 完整门禁：双 tsc → 全量测试 → 前端构建 → 4 个隔离 HTTP 夹具
```

`pnpm gate` 是这个项目的**发布前置条件**：任何一项红都不发版本。

## 架构一览

```
src/
  core/
    agent/        主循环、工具调用、steering（插话）、委派
    context/      上下文压缩、摘要、逐字回读
    memory/       项目记忆：提案 / 审批 / 应用 / 维护 AI
    model/        供应商适配（OpenAI 兼容）与思考强度
    tools/        内置工具与注册表（工具名校验、权限判定）
    store/        SQLite schema、迁移、仓储
    plugin/       插件宿主与清单
    mcp/          MCP 客户端与配置
  server/         Fastify 路由 + SSE + 信任围栏
  shared/         前后端共享类型与常量
web/              React 19 前端（Vite）
desktop/          Electron 外壳（main / preload）
test/             unit / e2e / HTTP 夹具
```

几条**贯穿全项目的原则**：

1. **可见性就是权限** —— 工具不进注册表，模型就调不到，不是靠提示词约束。
2. **AI 只提议，不拍板** —— 记忆、原则、审批都是这样。
3. **摘要必须能指回原文** —— 压缩不删数据，只换投影。
4. **判据必须是可观测行为** —— 测试断言的是请求字节、状态码、重启后的状态，不是「代码里有这个结构」。

## 已知限制

- **Windows 优先**：路径、权限标签（完整性级别）等实现偏 Windows。
- **未做多用户**：没有账号体系，服务只监听回环地址；不要把它直接暴露到公网。
- **没有云同步**：数据在单机上，迁移靠复制数据目录。
- **门禁之外**有一两个历史脚本是 Known-Red（在 `scripts/gate.mjs` 里显式列出原因），不会被当作绿灯。
